BusyBox in Kabuk: source code offer
===================================

Kabuk's Phone tab includes BusyBox 1.37.0 (https://busybox.net), licensed under the GNU General Public
License version 2 (see busybox-GPL-2.0.txt). It is shipped inside the APK as lib/<abi>/libbusybox.so.

Corresponding source:
  Tarball  https://busybox.net/downloads/busybox-1.37.0.tar.bz2
  SHA-256  3311dff32e746499f4df0d5df04d7eb396382d7e108bb9250e7b519b837043a4

How it is built: scripts/build-tools.sh in Kabuk's source repository (https://github.com/muratbilge/kabuk).
The script is the complete build recipe: busybox's defconfig with a list of applets switched off, linked
dynamically against Android's libc with the Android NDK r29 (29.0.14206865, API level 28). The busybox
source is used unmodified.

Written offer: for at least three years after you received this version of Kabuk, the author will give
anyone a copy of the corresponding source above (the tarball plus the build script) on request,
free of charge apart from the cost of physically providing it. Ask through Kabuk's GitHub repository.
